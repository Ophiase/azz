# Decision Records

This folder holds dated architecture decision records and audits:
point-in-time deep reflections on a subject, ending with a verdict.

- One file per subject: `YYYY-MM-DD-<topic>.md`.
- Each document is a snapshot of what we knew and decided **on that
  date** — it is not maintained afterwards. If a decision is revisited,
  write a new dated document that links back to the old one.
- Audience: future developers who want a digested starting point before
  reopening a big design question.
- These documents are **opt-in reading**: nothing in `.claude/` points
  here, so agents only read them when explicitly asked.
